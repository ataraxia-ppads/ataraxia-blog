## UC02 — Ler post

```mermaid
sequenceDiagram
    actor V as Visitante
    participant Vw as PostDetailView
    participant P as Post.published
    participant C as Comment.approved
    participant T as post_detail.html
    V->>Vw: GET /texto/slug/
    Vw->>P: get(slug)
    alt texto publicado
        P-->>Vw: post
        Vw->>C: filter(post)
        C-->>Vw: comentários aprovados
        Vw->>T: render(post, comentários)
        T-->>V: página do texto
    else inexistente ou em rascunho
        P-->>Vw: DoesNotExist
        Vw-->>V: erro 404
    end
```

**Figura 21 — Sequência de projeto do UC02**

A view consulta `Post.published`, e não o gerenciador padrão. É por isso que
rascunho e endereço inexistente terminam no mesmo 404 sem que a view escreva uma
condição para cada caso, o que atende RN01.

O formulário de comentário é montado pelo template, e só quando há sessão. A
view não decide isso.
