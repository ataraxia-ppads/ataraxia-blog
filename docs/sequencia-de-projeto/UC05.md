## UC05 — Cadastrar-se

```mermaid
sequenceDiagram
    actor V as Visitante
    participant Vw as SignUpView
    participant F as SignUpForm
    participant Us as User
    participant Pf as Profile
    V->>Vw: POST /cadastro/
    Vw->>F: is_valid()
    alt dados aceitos
        Vw->>F: save()
        F->>Us: save(), senha em hash
        Us->>Pf: sinal create_profile
        Pf-->>Us: perfil
        Us-->>F: usuário
        F-->>Vw: conta e perfil gravados
        Vw->>Vw: login()
        Vw-->>V: redireciona para a listagem
    else nome de usuário ou email em uso
        F-->>Vw: erro no campo em conflito
        Vw-->>V: formulário sem a senha
    else senha recusada
        F-->>Vw: regra de robustez não atendida
        Vw-->>V: formulário com o motivo
    end
```

**Figura 22 — Sequência de projeto do UC05**

O perfil nasce pelo sinal `create_profile`, disparado quando a conta é gravada, e é o que impede usuário sem perfil, venha a conta do cadastro, do admin ou do `createsuperuser`. A senha nunca chega ao banco como texto puro: o `save()` herdado do `UserCreationForm` grava o hash, o que é RN06.
