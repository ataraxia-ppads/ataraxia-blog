## UC05 — Cadastrar-se

```mermaid
sequenceDiagram
    actor V as Visitante
    participant U as urls.py
    participant Vw as SignUpView
    participant F as SignUpForm
    participant Us as User
    participant Pf as Profile
    V->>U: POST /cadastro/
    U->>Vw: dispatch()
    Vw->>F: is_valid()
    alt dados aceitos
        F->>Us: create_user(), senha gravada como hash
        Us-->>F: usuário
        F->>Pf: create(user)
        Pf-->>F: perfil
        F-->>Vw: conta e perfil gravados
        Vw->>Vw: login()
        Vw-->>V: redireciona para a listagem
    else nome de usuário ou email em uso
        F-->>Vw: erro no campo em conflito
        Vw-->>V: formulário reexibido, sem a senha
    else senha recusada
        F-->>Vw: regra de robustez não atendida
        Vw-->>V: formulário reexibido, com o motivo
    end
```

**Figura 23 — Sequência de projeto do UC05**

Conta e perfil são criados na mesma passagem pelo formulário, e é o que impede
usuário sem perfil. A senha nunca transita como texto puro para o modelo:
`create_user()` já grava o hash, o que é RN06.
