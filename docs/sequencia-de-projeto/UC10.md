## UC10 — Comentar post

```mermaid
sequenceDiagram
    actor A as Autor
    participant U as urls.py
    participant Vw as CommentCreateView
    participant P as Post.published
    participant F as CommentForm
    participant C as Comment
    A->>U: POST /texto/slug/comentar/
    U->>Vw: dispatch()
    Vw->>P: get(slug)
    alt texto publicado e comentário aceito
        P-->>Vw: post
        Vw->>F: is_valid()
        F->>C: save(), approved verdadeiro, autor e data
        C-->>F: comentário gravado
        F-->>Vw: instância
        Vw-->>A: redireciona para a página do texto
    else corpo vazio ou acima do máximo
        F-->>Vw: erro de validação
        Vw-->>A: formulário reexibido, texto preservado
    else texto despublicado durante a escrita
        P-->>Vw: DoesNotExist
        Vw-->>A: gravação recusada
    end
```

**Figura 22 — Sequência de projeto do UC10**

A view confirma que o texto continua publicado antes de gravar, e não apenas na
hora de exibir o formulário. Sem isso, um texto despublicado enquanto alguém
escreve receberia comentário.

O autor do comentário vem da sessão, nunca do formulário, o que atende RN16.
