## UC08 — Manter post

**Tabela 11 — Caso de uso UC08 — Manter post**

| Campo | Conteúdo |
| ----- | -------- |
| Identificador | UC08 |
| Ator principal | Autor |
| Atores secundários | — |
| Pré-condições | O autor está autenticado |
| Pós-condições | O texto é criado, alterado ou excluído, e a listagem reflete a alteração |

Manter designa criar, ler, atualizar e excluir.

### Fluxo principal — criar

1. O autor aciona a opção de escrever texto.
2. O sistema exibe o formulário com título, corpo, categoria e tags.
3. O autor preenche os campos e salva.
4. O sistema valida que título e corpo não estão vazios.
5. O sistema gera o *slug* a partir do título.
6. O sistema grava o texto no estado `DRAFT`, registrando autoria e data de criação.
7. O sistema exibe o texto na lista de rascunhos do autor.

### Fluxos alternativos

**A1 — Alterar texto existente** (no passo 1)

1. O autor seleciona um de seus textos e aciona a edição.
2. O sistema verifica que o texto pertence ao autor.
3. O sistema exibe o formulário preenchido.
4. O autor altera e salva.
5. O sistema grava a alteração e registra a data de modificação.
6. O fluxo se encerra.

**A2 — Excluir texto** (no passo 1)

1. O autor seleciona um de seus textos e aciona a exclusão.
2. O sistema verifica que o texto pertence ao autor.
3. O sistema pede confirmação, informando que a ação é irreversível.
4. O autor confirma.
5. O sistema exclui o texto e os comentários vinculados a ele.
6. O fluxo se encerra.

**A3 — Slug já existente** (no passo 5)

1. O sistema acrescenta um sufixo numérico ao slug até obter um valor livre.
2. O fluxo segue no passo 6.

### Fluxos de exceção

**E1 — Campo obrigatório vazio** (no passo 4)

1. O sistema indica os campos pendentes.
2. O sistema reexibe o formulário preservando o que foi digitado.
3. O fluxo retorna ao passo 3.

**E2 — Texto de outro autor** (nos passos A1.2 e A2.2)

1. O sistema responde com erro 403.
2. O fluxo se encerra.

### Regras de negócio

- **RN09 —** O autor só edita ou exclui textos de sua própria autoria. A
  verificação é feita no servidor, e não apenas ocultando o botão na tela.
- **RN10 —** O slug é imutável depois da primeira publicação, para não quebrar
  endereços já divulgados.
- **RN11 —** Excluir um texto exclui os comentários vinculados. Não há
  comentário órfão.
- **RN12 —** Todo texto nasce como rascunho. A transição para publicado é
  ato explícito, descrito em UC09.
