# UC02 — Ler post

| Campo | Conteúdo |
| ----- | -------- |
| Identificador | UC02 |
| Ator principal | Visitante |
| Atores secundários | — |
| Pré-condições | O texto existe e está no estado `PUBLISHED` |
| Pós-condições | O texto é exibido integralmente, com seus comentários aprovados |

## Fluxo principal

1. O visitante seleciona um texto na listagem.
2. O sistema recupera o texto pelo seu endereço.
3. O sistema verifica que o texto está publicado.
4. O sistema exibe título, autor, data de publicação, categoria, tags e corpo.
5. O sistema exibe os comentários aprovados, do mais antigo para o mais recente.
6. O sistema exibe o formulário de comentário, se o visitante estiver autenticado.

## Fluxos alternativos

**A1 — Visitante não autenticado** (no passo 6)

1. O sistema exibe, no lugar do formulário, um convite para entrar ou cadastrar-se.
2. O fluxo se encerra.

**A2 — Texto sem comentários** (no passo 5)

1. O sistema informa que ainda não há comentários.
2. O fluxo segue no passo 6.

## Fluxos de exceção

**E1 — Texto não encontrado** (no passo 2)

1. O sistema exibe a página de erro 404.
2. O fluxo se encerra.

**E2 — Texto em rascunho** (no passo 3)

1. O sistema exibe a página de erro 404, sem revelar que o texto existe.
2. O fluxo se encerra.

## Regras de negócio

- **RN01 —** Rascunho é invisível para quem não é o autor. O sistema responde
  404, e não 403, para não confirmar a existência do texto.
- **RN02 —** Comentário não aprovado não aparece para ninguém além do moderador.
