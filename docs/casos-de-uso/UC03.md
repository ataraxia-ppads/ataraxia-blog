## UC03 — Buscar post

**Tabela 9 — Caso de uso UC03 — Buscar post**

| Campo | Conteúdo |
| ------------------ | ---------------------------------------------------------- |
| Identificador | UC03 |
| Ator principal | Visitante |
| Atores secundários | — |
| Pré-condições | Nenhuma |
| Pós-condições | A listagem exibe apenas os textos publicados que contêm o termo buscado |

Estende UC01 — Listar posts publicados.

### Fluxo principal

1. O visitante digita um termo no campo de busca da listagem e confirma.
2. O sistema descarta os espaços nas pontas do termo.
3. O sistema procura o termo no título e no corpo dos textos publicados.
4. O sistema ordena os textos encontrados pela data de publicação, do mais
   recente para o mais antigo.
5. O sistema exibe a listagem paginada, com a quantidade de textos encontrados
   e o termo mantido no campo de busca.
6. O sistema oferece a opção de limpar a busca.

### Fluxos alternativos

**A1 — Termo vazio** (no passo 2)

1. O sistema exibe a listagem completa, como em UC01.
2. O fluxo se encerra.

**A2 — Troca de página** (no passo 5)

1. O visitante avança ou volta uma página.
2. O sistema repete a busca com o mesmo termo, para a página pedida.
3. O fluxo segue no passo 5.

### Fluxos de exceção

**E1 — Nenhum texto encontrado** (no passo 3)

1. O sistema informa que nada foi encontrado para o termo.
2. O sistema oferece a opção de voltar à listagem completa.
3. O fluxo se encerra.

**E2 — Página inexistente** (no passo 5)

1. O sistema exibe a página de erro 404.
2. O fluxo se encerra.

### Regras de negócio

- **RN03 —** A busca considera o título e o corpo do texto, sem diferenciar
  maiúsculas de minúsculas. O termo é tratado sempre como texto, nunca como
  parte da consulta ao banco.
- **RN04 —** Rascunho nunca aparece no resultado nem entra na contagem, mesmo
  quando contém o termo buscado.
- **RN05 —** O termo vai no endereço, como `/?q=termo`, para que a busca possa
  ser repetida pelo link e para que a troca de página o preserve.
