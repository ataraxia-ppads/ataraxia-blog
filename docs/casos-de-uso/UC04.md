# UC04 — Filtrar por categoria ou tag

| Campo | Conteúdo |
| ----- | -------- |
| Identificador | UC04 |
| Ator principal | Visitante |
| Atores secundários | — |
| Pré-condições | Nenhuma |
| Pós-condições | A listagem exibe apenas os textos publicados que pertencem ao filtro escolhido |

Estende UC01 — Listar posts publicados.

## Fluxo principal

1. O visitante seleciona uma categoria ou uma tag, na listagem ou na página de um texto.
2. O sistema recupera os textos publicados associados ao termo escolhido.
3. O sistema ordena os textos pela data de publicação, do mais recente para o mais antigo.
4. O sistema exibe a listagem paginada, indicando qual filtro está aplicado.
5. O sistema oferece a opção de remover o filtro.

## Fluxos alternativos

**A1 — Nenhum texto no filtro** (no passo 4)

1. O sistema informa que não há textos nessa categoria ou tag.
2. O sistema oferece a opção de voltar à listagem completa.
3. O fluxo se encerra.

**A2 — Filtro combinado com busca** (no passo 2)

1. O sistema aplica o termo de busca sobre o conjunto já restrito pelo filtro.
2. O fluxo segue no passo 3.

## Fluxos de exceção

**E1 — Categoria ou tag inexistente** (no passo 2)

1. O sistema exibe a página de erro 404.
2. O fluxo se encerra.

## Regras de negócio

- **RN03 —** Um texto pertence a exatamente uma categoria e a zero ou mais tags.
- **RN04 —** Categoria e tag são identificadas na URL por *slug*, não por número,
  para que o endereço seja legível e estável.
- **RN05 —** Rascunhos nunca entram na contagem nem na listagem, mesmo quando
  associados ao termo filtrado.
